Installing BlinkBlink Update

Important: Please follow these steps in order to properly update BlinkBlink.

Step 1: Quit BlinkBlink

1. Click the BlinkBlink icon in your menu bar

2. Select "Quit" from the menu

3. Wait a few seconds for the app to close completely

Step 2: Install the New Version

1. Double-click the downloaded DMG file (named BlinkBlink.Setup.x.x.x.dmg)

2. Drag BlinkBlink.app to your Applications folder

3. Click "Replace" if prompted

Step 3: Remove Security Restrictions

1. Open Terminal (press Cmd+Space and type "Terminal")

2. Copy and paste this command:

xattr -c /Applications/BlinkBlink.app

3. Press Enter to run the command

Step 4: Start BlinkBlink

1. Open BlinkBlink from your Applications folder

2. If you see a security warning, open System Settings → Privacy & Security and click "Open Anyway"
